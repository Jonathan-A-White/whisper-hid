# Best-practices audit

Audit of whisper-hid against the factory's PWA best practices (the vault's
`seats/builder/pwa-best-practices/checklist.md` and the section each line points to),
including the rules added on 2026-10-09, and `library-best-practices/01` for shared code.
Written 2026-10-10 at commit 626a699 (main); docs only, no behaviour changed.

Whisper-hid has three parts. Only the **PWA** (`pwa/`) is a PWA. The Android app (`app/`,
Kotlin: a headless Bluetooth HID service) and the Termux server (`scripts/`, Python) are not
PWAs, so every PWA row is n/a for them and is judged on `pwa/` alone.

How to read the tables:

- **Status** is `pass`, `fail` or `n/a`. A checklist line with several parts is `fail` if any
  part that applies fails; the evidence names the parts.
- **Evidence** is a `file:line` (checked by `docs/check-best-practices-audit.py`), a command and
  what it printed, or the reason the line does not apply.
- **Fix** is the smallest change that turns a fail into a pass; **Size** is S (one sitting, up to
  three files), M (a few hours, four to ten files) or L (a day or more, new tooling).
- These checks ran against the live site, `https://jonathan-a-white.github.io/whisper-hid/`, on
  2026-10-10: `curl -s -o /dev/null -w '%{http_code}' <site>/icon-192.png` printed `404` (so did
  `icon-512.png` and `404.html`), `manifest.webmanifest` and `sw.js` printed `200`.
- `cd pwa && npm ci && npm run build` ran clean at this commit: the tests and `tsc` pass, and
  Workbox reports `precache 5 entries (300.64 KiB)`; `dist/` holds `index.html`, `sw.js`,
  `manifest.webmanifest` and `assets/`, and no icon files.

Tally: of the 32 checklist lines, 8 pass, 19 fail and 5 n/a; of the 6 rules added 2026-10-09,
3 pass, 1 fails and 2 are n/a.
